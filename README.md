# hxyfront-62011 马术蹄铁修整档案

面向马术俱乐部蹄铁师的日常修蹄记录台：登记即入档、复查到期提醒、换铁历史可追溯，数据保存在浏览器本地。

## 功能

- **修蹄登记**：马号、马匹分类、修蹄日期、步态问题、蹄形评估、四蹄（左前/右前/左后/右后）状态与钉位、蹄铁类型、下次复查、备注；保存后列表立即更新。
- **同马衔接**：输入已有马号会识别旧档案，本次记录接在该马历史后面，并自动把上次换上的蹄铁类型记为本次「换铁前」，形成 `旧类型 → 新类型` 的换铁链路。
- **复查提醒**：复查日逾期 / 今天 / 7 天内到期的马匹自动进入提醒区并按紧急程度排序；「标记已处理」后不再催促，历史中仍可查到并可撤销。
- **档案列表**：按前蹄 / 后蹄异常、运动马 / 休养马筛选，支持马号搜索；展开任意马匹可看历次修蹄时间线、四蹄对比、异常步态标记与换型记录。
- **本地持久化**：数据存于 `localStorage`（键 `farrier-archive-v1`），关闭浏览器再打开仍在；支持导出 CSV（含 BOM，Excel 可直接打开）备份。

## 结构（记录 / 计算 / 展示分层）

```
src/
  types.ts              数据模型
  constants.ts          蹄位、蹄铁类型、异常关键词等常量
  lib/
    storage.ts          本地存储读写 + 数据消毒（记录层）
    selectors.ts        列表、提醒、指标、筛选等纯计算（计算层）
    date.ts / id.ts / csv.ts  日期、ID、导出工具
    useArchive.ts       React 状态编排，联动存储与计算
  components/           MetricsBar / ReminderPanel / RecordForm / HorseList（展示层）
  App.tsx               页面装配
```
